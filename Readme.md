- task1.c - основной файл с задачей
- qwerty.py - файл чтобы заполнять bin файлы


## Запуск:

Компиляция:

`
mpicc -o program.x task1.c -ldl -lm -L$HOME/scalapack-install/lib -lscalapack -llapack -lblas -lgfortran
`

Запуск:

`
mpirun -np 4 ./program.x 4 mro.bin 0.1 test_H.bin 1
`

Параметры запуска:

- -np 4 - процессы
- 4 - N
- mro.bin - файл для ro (пока что для скаляра и вектора нужны txt файлы, а для матрицы - bin)
- 0.1 - dT
- test_H.bin - файл для H
- 1 - n
